rb-cli mkdir

Create a directory inside a filesystem

Usage

Usage: mkdir [OPTIONS] <IMAGE> <PATH>

Arguments

<IMAGE>
Image reference (`path` or `path@N` for the 1-based partition index)
<PATH>
Directory path to create. The parent must exist (no `-p`-style auto-creation in Phase B). A literal `/` in the new name is written `\/`; on HFS / HFS+ a `:`-separated path also works

Options

-L / --literal
Accepted for consistency with `ls`/`get`/`rm`; `mkdir` always treats the path as an exact literal path (it never globs), so glob metacharacters in a name are used verbatim with or without it
