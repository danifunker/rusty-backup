rb-cli swab16

Swap the two bytes of every 16-bit word in a disk image. Fixes up a capture taken through a controller that reverses words (e.g. SGI IRIS disks); the transform is its own inverse

Usage

Usage: swab16 [OPTIONS] <INPUT> [OUTPUT]

Arguments

<INPUT>
Image to convert
<OUTPUT>
Destination image. Omit when passing `--in-place`

Options

--in-place
Rewrite INPUT itself instead of writing a separate OUTPUT
--force
Overwrite OUTPUT when it already exists
