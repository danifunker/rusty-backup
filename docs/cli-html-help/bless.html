rb-cli bless

Inspect or set the bootable System Folder on an HFS / HFS+ volume (`set` / `show` / `pick`)

Usage

Usage: bless <COMMAND>

Subcommands

  • setBless the folder at PATH (mark it as the bootable System Folder)
  • showPrint the volume's current blessed System Folder
  • pickInteractively browse the volume's folders and pick one to bless
