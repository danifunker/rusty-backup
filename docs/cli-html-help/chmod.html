rb-cli chmod

Change POSIX permission bits on an entry inside an image. Works on every filesystem that stores a Unix mode — ext, EFS, UFS, Minix, JFS, XFS, SquashFS, and HFS+ (its `HFSPlusBSDInfo`, which is how OS X carries permissions)

Usage

Usage: chmod <IMAGE> <PATH> <MODE>

Arguments

<IMAGE>
Image reference (`path` or `path@N` for the 1-based partition index)
<PATH>
Absolute path of the entry inside the filesystem
<MODE>
New permission bits in octal, with or without a leading `0` (`755`, `0644`, `4755` for setuid). The file-type bits are kept
