rb-cli optical boot replace

Replace a boot image with the bytes of a (edited) disk-image file. Raw `.iso` only; same-size replaces in place, a grown image relocates

Usage

Usage: replace [OPTIONS] --from <FROM> <SOURCE>

Arguments

<SOURCE>
Bootable optical image to edit — raw `.iso` only

Options

--from
Disk-image file whose bytes become the new boot image
--index
Which boot entry to replace (default 0)
--media
Override the emulation/media type (default: keep the entry's current one). One of `floppy1.2` / `floppy1.44` / `floppy2.88` / `no-emulation` / `harddisk`
