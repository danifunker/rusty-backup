rb-cli optical boot extract

Extract a boot image to a file — then inspect or edit it with the disk-image verbs, and put it back with `optical boot replace`

Usage

Usage: extract [OPTIONS] --to <TO> <SOURCE>

Arguments

<SOURCE>
Bootable optical disc image (.iso, …)

Options

--to
Destination file for the extracted boot image
--index
Which boot entry to extract (default 0; see `optical info`)
