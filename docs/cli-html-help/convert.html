rb-cli convert

Re-encode one or more disk images into a chosen output format

Usage

Usage: convert [OPTIONS] <IN> <OUT>

Arguments

<SOURCE>
Source image or folder. A folder converts every image it holds
<DEST>
Destination folder. Created if absent

Options

--format
Output format, for every kind that offers it: raw, vhd, vhd-dynamic, qcow2, vmdk-flat, vmdk-sparse, 2mg, chd (hard disks); raw, 2mg, woz, moof, dc42, xdf, hdm, dim, d88 (floppies); chd-cd, chd-dvd, bincue, iso (discs)
--floppy-to
The floppies' format, overriding --format for them
--disc-to
The discs' format, overriding --format for them
--extension
Output extension (no leading dot) for the kinds --format sets. Defaults to the format's
--recursive
Also convert the images in every subfolder; the output keeps the same folders
--size
Hard disk size: keep, minimum, minimum+64MB or minimum+10% (the extra goes on every partition, and never past the partition's original size)
--measure-slow
Also measure filesystems that need a full read to find their minimum (HFS, ext, UFS, EFS). Without it those partitions keep their size
--floppy-size
Floppy size: same, or refit to 360k, 720k, 800k, 880k, 1.2m, 1.44m, 1.76m or 2.88m (a blank disk of that size with every file copied across)
--verify
Read each output back and compare it with its source
--bincue-multi-bin
For BIN/CUE output, write one .bin per track instead of a single concatenated .bin
--overwrite
Overwrite destination files that already exist. Without this they are skipped
