rb-cli repack

Defragment a Human68k (X68000) partition in place: clone it into a fresh, contiguously-packed volume and write that back. Reclaims holes the in-place resizer can't (it keeps cluster byte-offsets)

Usage

Usage: repack [OPTIONS] <IMAGE>

Arguments

<IMAGE>
Image reference (`path` or `path@N` for the 1-based partition index)

Options

--size
New filesystem size in bytes (default: the partition's current size). Accepts suffixes (`K`, `M`, `G`). Must not exceed the partition capacity
