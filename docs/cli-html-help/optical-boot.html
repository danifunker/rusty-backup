rb-cli optical boot

Work with El Torito boot images (extract / replace)

Usage

Usage: boot <COMMAND>

Subcommands

  • extractExtract a boot image to a file — then inspect or edit it with the disk-image verbs, and put it back with `optical boot replace`
  • replaceReplace a boot image with the bytes of a (edited) disk-image file. Raw `.iso` only; same-size replaces in place, a grown image relocates
