rb-cli optical drives

List connected physical optical drives and their device paths

Usage

Usage: drives [OPTIONS]

Options

--remote
Also query these daemons for their optical drives (repeatable), e.g. `--remote mister.local:7341`. Remote rows print an `rb://...` device arg you can pass straight to `optical rip --device`
