rb-cli get-binhex

Extract a file and encode it as BinHex 4.0 (.hqx), preserving both forks and the type/creator codes

Usage

Usage: get-binhex [OPTIONS] <IMAGE> <SRC> <DST>

Arguments

<IMAGE>
Image reference (`path` or `path@N`)
<SRC>
Source path inside the filesystem
<DST>
Destination `.hqx` path on the host

Options

--password
Password for encrypted containers (WinImage IMZ) or an encrypted filesystem (APFS FileVault — the volume password or recovery key)
-L / --literal
Accepted for consistency with `ls`/`get`/`rm`; `get-binhex` always treats the source as an exact literal path (it never globs), so glob metacharacters in a name are addressed verbatim with or without it. A literal `/` in a name is written `\/` (or use a `:`-separated path on HFS / HFS+)
