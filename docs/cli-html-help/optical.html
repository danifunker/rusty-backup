rb-cli optical

Optical-media verbs (drives / rip / convert / browse / extract)

Usage

Usage: optical <COMMAND>

Subcommands

  • browseList the file tree on an optical disc image
  • duRecursive both-fork (data + resource) disk usage of paths on an optical disc image — the disc counterpart of the top-level `du` verb, for hybrid Mac discs whose apps keep code in the resource fork

  • extractExtract files from an optical disc image into a host folder
