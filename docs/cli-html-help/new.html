rb-cli new

Create a blank image, grouped by media class: `new floppy <fs>`, `new volume <fs>` (bare superfloppy), or `new hd {x68k|sgi-efs}` (partition-table-wrapped, bootable). CD-ROM images are under `optical new`; multi-partition images go through `batch`

Usage

Usage: new <COMMAND>

Subcommands

  • floppyBlank floppy-geometry single volume (bare, no partition table): FAT / HFS and the fixed-geometry retro filesystems
  • volumeBlank bare single volume of arbitrary size (a "superfloppy"): the larger filesystems (NTFS, ext, HFS+, EFS, AFFS, …). No partition table
  • hdPartition-table-wrapped, self-bootable hard-disk image
