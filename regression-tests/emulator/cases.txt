#   <id>  <known bug or ->  <script and arguments, relative to emulator/>

# --controls skips it: Windows self-heals a damaged blank NTFS volume on mount,
# before chkdsk runs (README, Controls).

# fixed: it does not fail the run, and its passing is reported so the bug can
# be closed. Scenarios exit 0 pass, 1 finding, 77 cannot run here, 99 no verdict.
