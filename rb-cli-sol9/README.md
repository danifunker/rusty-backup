# rb-cli-sol9

The mrustc / Solaris 9 SPARC build of `rb-cli` and its TUI - a fourth
self-contained top-level package alongside `rb-cli-vintage` (macOS 10.7 /
Windows 7) and `rb-cli-ppc` (PowerPC Mac OS X). It reuses the shared engine
under `../src` and carries only the dependency deviations mrustc and Solaris 9
force.

Target: `sparcv9-sun-solaris2.9` - 64-bit big-endian SPARC V9, cross-compiled
from Linux with gcc 4.9.4. Unlike the PowerPC build there is no two-machine
model; only the finished binary goes to the hardware.

**Status: scoping.** Nothing is built yet. Read
[`../docs/build-sol9-mrustc.md`](../docs/build-sol9-mrustc.md) for what is
already verified (the mrustc target, the cross toolchain and the Rust stdlib all
exist), what the open findings are, and what the work is.

`vendor/` is generated by `cargo vendor` and gitignored.
